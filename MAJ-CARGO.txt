3. ARCHITECTURE FIRESTORE
──────────────────────────────────────────────
Projet Firebase : cargo-optimizer-fca82
Collection      : cargo_sessions
Règles          : Lecture/écriture publique (sans authentification)

Structure d'un document cargo_sessions :
  - id (string)           : Identifiant unique de session
  - name (string)         : Nom du chargement
  - created (string)      : Date de création (format FR)
  - container (map)       : Dimensions {l, w, h, max, type}
  - colis (array)         : Liste des colis [colorIdx, ref, L, l, H, qty, poids, rotation, fragilite]
  - updatedAt (timestamp) : Horodatage serveur Firestore

Synchronisation :
  - Écouteur temps réel (onSnapshot) sur la collection cargo_sessions
  - Tri par updatedAt décroissant (plus récents en premier)
  - Sauvegarde automatique à chaque modification
